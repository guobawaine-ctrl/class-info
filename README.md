# 班级信息站（免费静态网页模板）

一个单文件静态信息页，覆盖公告、日程、文件、链接、班委、班费六个板块。80 人班级完全够用，部署成本为 0，不需要服务器。

线上地址：<https://guobawaine-ctrl.github.io/class-info/>

## 怎么改内容

直接打开 `index.html` 编辑：

- 标题、班级名、通知、日期：直接改中文文字。
- 文件卡片和常用链接：把 `href="#"` 替换成真实网址。
- 班委名单、班费明细：替换“待选举”“暂无记录”等内容。

改完重新上传即可，不用安装任何软件。

## 本地预览

- 最简单：双击 `index.html` 用浏览器打开。
- 或者启动一个本地服务：`python -m http.server 8000`，然后访问 `http://localhost:8000`。

## 三种方案怎么选

| 方案 | 成本 | 难度 | 适合场景 |
| --- | --- | --- | --- |
| 飞书知识库 / 腾讯文档 / Notion 公开页 | 0 元 | 最低 | 想 5 分钟上线、多人随时编辑 |
| GitHub Pages / Cloudflare Pages | 0 元 | 中等 | 想要一个真正独立网页、长期沉淀 |
| Gitee Pages | 0 元（需实名） | 中等 | 希望国内访问更稳定 |
| 腾讯云 COS / 阿里云 OSS 静态托管 | 几元/月 | 中等 | 想要国内稳定访问又不依赖 Pages |
| 云服务器 | 几十元/月 | 较高 | 目前不需要，纯浪费预算 |

如果只是想让全班“有个地方看信息”，飞书/腾讯文档是当天就能用上的方案。如果想要一个像样的独立网页，用本仓库的 `index.html` 部署到 GitHub Pages 即可。

## GitHub Pages 部署步骤（免费）

1. 注册并登录 GitHub，新建一个公开仓库，例如 `class-info`。
2. 把 `index.html`（README 可选）上传到仓库。
3. 打开仓库 Settings → Pages，Source 选择 `main` 分支，目录选 `/ (root)`。
4. 等一两分钟，访问 `https://guobawaine-ctrl.github.io/class-info/`。

想要更短的网址可以买域名（约 30–80 元/年），非必需。

## 注意事项

- 静态网页对所有人可见，不要在页面放身份证号、手机号、成绩单等敏感信息；私密内容放班群或飞书/腾讯文档。
- 通知、链接、班费这类低更新频率内容，静态页面足够；如果需要多人实时编辑，直接选文档方案。
