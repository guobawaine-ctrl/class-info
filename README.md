# 班级信息站（免费静态网页模板）

一个单文件静态信息页，覆盖公告、日程、文件、链接、班委、班费六个板块。

线上地址：<https://guobawaine-ctrl.github.io/class-info/>

## 本地预览

- 最简单：双击 `index.html` 用浏览器打开。
- 或者启动一个本地服务：`python -m http.server 8000`，然后访问 `http://localhost:8000`。


## 注意事项

- 静态网页对所有人可见，不要在页面放身份证号、手机号、成绩单等敏感信息；私密内容放班群或飞书/腾讯文档。
- 通知、链接、班费这类低更新频率内容，静态页面足够；如果需要多人实时编辑，直接选文档方案。
